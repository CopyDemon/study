# Learn FastAPI from Youtube
## Resource: 
### [Video Link](https://www.youtube.com/watch?v=XnYYwcOfcn8&list=PLqAmigZvYxIL9dnYeZEhMoHcoP4zop8-p&index=1)

* Packages:
    * FastAPI 
    * uvicorn[standard]
    * Python 3.10
    * environment: venv env

* How to use:
    1. Clone repo and nav to this folder,(I believe you are here or you cant see this file lol)
    2. Create virtual environment: 
        ```bash
        python -m venv env
        ```
    3. if in conda env: 
        ```bash
        (base)username ~/
        ```
        have to run:
        ```
        conda deactivate
        ```
        then run code below:
    4. Source virtual environment: 
        ```bash
        source ./env/bin/activate
        ```
    5. Install dependency: 

        ```bash
        pip install -r requirements.txt
        ```

* Leave this working environment:
    * Once finished working on this env, need to back to the env you working on before:
        ```bash
        deactivate
        ```
