## 🔍 核心技术要点

### 关键API调用

```python
# 1. 初始化客户端
from mp_api.client import MPRester
mpr = MPRester(api_key="你的API密钥")

# 2. 查询所有项目
projects = mpr.contribs.query_projects(fields=["name", "title"])

# 3. 查找特定项目
target_project = None
for project in projects:
    if project.get("name") == "carrier_transport":
        target_project = project
        break

# 4. 查询项目的contributions
contributions = mpr.contribs.query_contributions(
    query={"project": "carrier_transport"}
)

# 5. 处理查询结果
if isinstance(contributions, dict):
    contributions_list = contributions.get('data', [])
    total_count = contributions.get('total_doc', len(contributions_list))
```

### 重要注意事项

1. **API选择**: 使用 `MPRester` 而不是 `mpcontribs.client.Client`
2. **项目名称**: 必须使用精确的API名称（如 `carrier_transport`）
3. **查询格式**: 使用字典格式 `{"project": "项目名称"}`
4. **结果处理**: API可能返回字典格式，需要提取 `data` 字段
5. **错误处理**: 合理处理项目不存在、网络错误等情况

## 🔧 故障排除

### 常见问题

1. **Q**: 项目名称找不到？
   **A**: 检查名称是否精确匹配，使用 `list_all_project_names()` 查看所有可用名称

2. **Q**: API调用失败？
   **A**: 检查API密钥是否有效，网络连接是否正常

3. **Q**: 数据量不对？
   **A**: 注意API分页机制，使用正确的查询参数

### 数据缓存

```python
# 缓存项目列表避免重复查询
cached_projects = None

def get_cached_projects():
    global cached_projects
    if cached_projects is None:
        cached_projects = mpr.contribs.query_projects()
    return cached_projects
```
